## Discussion

### 1. CRC-24b Implementation and 8-Bit Register Cascading
- Cyrus walked the team through the 3GPP TS 36.212 CRC-24b generator polynomial $g_{\text{CRC24B}}(D) = D^{24} + D^{23} + D^6 + D^5 + D + 1$, represented as the 24-bit hexadecimal mask `0x800063`.
- Because the STC89C52 ALU and general-purpose registers (`R0`–`R7`, `A`, `B`) are 8 bits wide, the 24-bit shift register is partitioned across three registers in Bank 0:
  - **`R5` (High Byte):** Bits 23..16
  - **`R6` (Mid Byte):** Bits 15..8
  - **`R7` (Low Byte):** Bits 7..0
- In `CRC24b.step8051Hardware()`, each incoming byte is XORed into `R5`, and the 24-bit value is shifted left bit-by-bit through the carry bit across `R7 -> R6 -> R5`. Whenever the MSB shifted out of `R5` is `1`, the registers are XORed with `0x80`, `0x00`, and `0x63` respectively in $GF(2)$ arithmetic.

### 2. Transmitter Encoding and Receiver Syndrome Verification
- Shashidhara and Chrisel reviewed the end-to-end verification flow on the Web Dashboard (`Port 8080`) and in `TestCRC24b.java`:
  - **Encoding:** Input vector `"123456789"` produces the 24-bit remainder `0x23EF52` (`R5=0x23`, `R6=0xEF`, `R7=0x52`) and 12-byte codeword `31 32 33 34 35 36 37 38 39 23 EF 52`.
  - **Clean Channel Decoding:** Passing the unmodified codeword through `CRC24b.decode()` produces syndrome `0x000000` (zero errors).
  - **1-Bit Noise Injection:** Flipping bit 0 (LSB) of byte 0 (`0x31 -> 0x30`) produces non-zero syndrome `0x520000`.
  - **2-Bit Adjacent Burst Injection:** Flipping bits 0 and 1 of byte 0 (`0x31 -> 0x32`) produces non-zero syndrome `0xF60000`.

### 3. Multi-Process Logging and Non-Blocking Queuing
- Arnold and Cyrus reviewed `LoggerProcess.java` (`Port 5001`) and `LogHandler.java`.
- Decoupling logging into an independent process prevents disk write latency on `simulator.log` from stalling the CPU execution loop in `CoreProcess` (`Port 5000`).
- `LogHandler.writeLog()` uses a `synchronized` method to ensure concurrent log frames are appended atomically without line interleaving, while `CoreProcess` buffers outbound log frames in a bounded non-blocking `ArrayBlockingQueue<String>(1024)`.
